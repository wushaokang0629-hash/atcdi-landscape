# 城市空间与园林分院宣传网站

电脑和手机使用同一网站，自动适配布局。手机模拟预览入口为 preview.html。

网站静态文件位于 dist。推送到 main 后，GitHub Actions 自动将 dist 发布至 GitHub Pages。Pages 发布源必须为 GitHub Actions。

本发布副本直接复制自 landscape-institute/dist，不修改网站内容。所有站内资源使用相对路径，适用于仓库子路径。
